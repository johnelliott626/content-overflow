## Documentation sources

Every page here is mirrored from another repository at build time. Nothing is
authored in this repository, so upstream stays the single place to make edits.

<CardGrid>
  {manifest.sources.map((source) => (
    <Card title={source.label} icon="open-book">
      <p>
        {source.pageCount} page{source.pageCount === 1 ? '' : 's'} mirrored from{' '}
        <a href={`https://github.com/${source.repo}/tree/${source.ref}/${source.path}`}>
          {source.repo}
        </a>
        .
      </p>
      <ul>
        {source.pages.slice(0, 5).map((page) => (
          <li>
            <a href={page.url}>{page.title}</a>
          </li>
        ))}
      </ul>
    </Card>
  ))}
</CardGrid>

## Adding another repository

Add an entry to `docs.sources.mjs` naming the repository, the branch and the
directory to pull from, then run `npm run sync`. The sidebar, this page and the
ignore rules all follow from that one entry.
